# 5G_summerfinal

**5G SA 코어 네트워크 취약점 점검 + 자동 조치 통합 도구**

KISA 「주요정보통신기반시설 기술적 취약점 분석·평가 방법 상세가이드(2026)」 기준
Unix 서버 67개 + DBMS(MongoDB) 26개 = **총 93개 항목** 자동 점검 및 조치

---

## 3단계 파이프라인

```
1단계 점검     checks/ 93개 모듈 실행 → 양호 / 취약 / 수동 / N/A 판정
      │
      ▼ 취약 항목만 전달
2단계 조치     fixes/ 해당 모듈 fix() 실행 → 조치완료 / 조치실패 / 수동제외
      │
      ▼ 조치완료 항목만 전달
3단계 재검증   checks/ 재실행 → 양호 전환 확인 (✓ / ✗)
```

### 핵심 원칙

- **안전성 우선**: 모든 변경 전 원본 백업(`/var/backups/5g-measure-tool/`), 실패 시 자동 롤백
- **최소 권한**: RBAC 관련 항목(D-02, D-04, D-11, D-18, D-20, D-24)은 자동 회수하지 않고 수동제외로 보고
- **읽기 전용 점검**: checks/ 모듈은 시스템을 절대 변경하지 않음
- **플러그인 구조**: checks/, fixes/ 에 파일 추가만으로 항목 확장 (main.py 수정 불필요)

## 빠른 시작

```bash
# 전체 파이프라인 (점검 → 조치 → 재검증)
sudo python3 main.py -u <MongoDB유저> -p '<MongoDB비밀번호>'

# 점검만 실행
sudo python3 main.py -u admin -p 'password' --check

# 조치만 실행 (점검 건너뜀)
sudo python3 main.py -u admin -p 'password' --fix

# 특정 항목만
sudo python3 main.py --only U-01 U-02 D-22

# 변경 없이 예정 동작만 확인
sudo python3 main.py -u admin -p 'password' --dry-run

# 결과 파일 저장
sudo python3 main.py -u admin -p 'password' --save results/report.txt
```

> `sudo` 필수 — `/etc/shadow` 등 시스템 파일 접근 및 설정 변경에 필요

## 조치 방식

| 유형 | 동작 | 대상 예시 |
|------|------|-----------|
| **자동 조치** | 설정 변경 → 검증 → 실패 시 롤백 | U-01(PermitRootLogin), D-22(maxIncomingConnections), D-23(javascriptEnabled) |
| **수동제외** | 취약 계정/권한 목록 보고 + 조치 명령어 안내 | D-04(관리자 과다), D-11(시스템 테이블 접근), D-18(전역 권한) |
| **N/A 반환** | 환경에 해당하지 않으면 건너뜀 | D-19(standalone MongoDB → 내부 인증 해당 없음) |

## 판정 기준

### 1단계 점검

| 상태 | 의미 |
|------|------|
| **양호** | KISA 가이드 기준 충족 |
| **취약** | 보안 설정 미흡 → 2단계로 전달 |
| **수동** | 자동 판별 불가, 수동 확인 기준 안내 출력 |
| **N/A** | 해당 없음 (Oracle/MSSQL 전용, standalone 등) |

### 2단계 조치

| 상태 | 의미 |
|------|------|
| **조치완료** | 취약 → 양호 자동 전환 성공 → 3단계로 전달 |
| **조치실패** | 조치 시도 실패, 원본 자동 복원 |
| **수동제외** | 자동 조치 불가, 수동 대응 가이드 출력 |

### 자동 조치된 항목

| 코드 | 항목 | 조치 내용 |
|------|------|-----------|
| D-22 | 자원 제한 | maxIncomingConnections: 1000 설정 |
| D-23 | JS 실행 제한 | javascriptEnabled: false 설정 |
| U-01 | root 원격 접속 | PermitRootLogin no |
| U-02 | 비밀번호 정책 | 복잡도(pwquality) + 이력(pwhistory) + 주기(login.defs) |
| U-03 | 계정 잠금 | pam_faillock deny=10, unlock_time=120 |
| U-06 | su 제한 | pam_wheel.so use_uid group=sudo |
| U-12 | 세션 타임아웃 | TMOUT=600 readonly |
| U-62 | 경고 메시지 | /etc/issue.net + SSH Banner 설정 |
| U-65 | NTP 동기화 | systemd-timesyncd 활성화 + 서버 설정 |

## 실행 옵션

| 옵션 | 설명 |
|------|------|
| `-u`, `--user` | MongoDB 인증 사용자 |
| `-p`, `--password` | MongoDB 인증 비밀번호 |
| `--check` | 1단계(점검)만 실행 |
| `--fix` | 2단계(조치)만 실행 |
| `--only` | 특정 항목만 실행 (예: `--only U-01 D-10`) |
| `--dry-run` | 실제 변경 없이 예정 동작만 출력 |
| `--save` | 결과를 텍스트 파일로 저장 |
